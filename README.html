Qualité logicielle

Principes SOLID

Principe Application concrète
S — SRP Chaque fichier a une seule raison de changer. Le nettoyage, la détection, le parsing et le formatage sont des responsabilités séparées.
O — OCP XmlFormatter étend ArticleFormatter sans modifier Sprint2Formatter. Un nouveau format = une nouvelle classe, aucun code existant modifié.
L — LSP PdfToTextConverter et Pdf2TxtConverter sont interchangeables partout où PdfConverter est attendu.
I — ISP Les interfaces sont petites et ciblées : PdfConverter n'expose qu'une méthode convert(), ArticleFormatter qu'une méthode format().
D — DIP batch_processor dépend de PdfConverter (abstraction) via la ConverterFactory, pas d'une implémentation concrète.

Utilisation

Lancer le parseur

python main.py misc -t
# Résultat dans misc/output/txt/ Boudin-Torres-2006.txt ✓ Das_Martins.txt ✓ Mikolov.txt ✓
python main.py misc -x
# Résultat dans misc/output/xml/ Boudin-Torres-2006.xml ✓ Das_Martins.xml ✓ Mikolov.xml ✓
python main.py misc -t -x
# Résultat dans misc/output/txt/ ET misc/output/xml/ Format : TEXTE + XML Traités : 10/10
# Choisir l'outil de conversion python main.py misc -x --outil pdf2txt # Aide complète python main.py --help

Dépannage

Problèmes fréquents

ModuleNotFoundError: No module named 'pdf_parser'

Lancer main.py depuis la racine du projet (le dossier qui contient le package pdf_parser/).

pdftotext: command not found

Installer poppler : sudo apt install poppler-utils. Ou utiliser --outil pdf2txt.

not well-formed (invalid token) dans le XML

Caractères de contrôle dans le PDF. Corrigé depuis le Sprint 3 par la fonction _nettoyer_xml().

Auteurs vides ou incorrects

PDF à double colonne ou sans couche texte. Essayer --outil pdf2txt.
